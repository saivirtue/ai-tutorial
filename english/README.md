# 英文口說練習（大人版）

這個資料夾是個人英文練習用，跟 repo 裡小孩的遊戲無關。

## 目標

- 解決的問題：聽得懂、說不順——組句卡頓、提取慢、有中文腔。
- 不做的事：單字卡、連續天數、需要每天主動打開的系統。

## 一天的樣子

| 時段 | 做什麼 | 要不要 |
|---|---|---|
| 騎車通勤 | 聽下載好的 podcast，同一集可以重複聽 | 有空才聽 |
| 午休 | 看 YouTube 推薦的 TED，不加義務 | 有空才看 |
| 晚上 2～5 分鐘 | 跟教練聊當天聽的內容，照 [daily-prompt.md](daily-prompt.md) | 想做才做 |

通勤時只聽、不看螢幕。耳機用單耳或骨傳導，音量要聽得到環境音。

## 通勤內容候選（用前自己確認逐字稿是否免費可看）

| 節目 | 特色 |
|---|---|
| BBC *6 Minute English* | 6 分鐘對話，網站有逐字稿 |
| NPR *Planet Money* | 經濟與日常議題，速度較快 |
| *WorkLife with Adam Grant* | 職場心理 |
| *All Ears English* | 美式日常口語 |
| *TED Talks Daily* | 午休看的 TED 也能直接當題材 |

在 Spotify / Apple Podcasts / YouTube Music 搜尋，Wi-Fi 下先下載離線。

## 兩週試用

先不寫程式，用提示詞跑兩週，之後再決定：

- 還在用 → 考慮做錄音＋可編輯語音轉文字的頁面，把流程縮短。
- 沒在用 → 不做，改調整方向。

試用期間留意：
1. 實際做了幾天、每次多久。
2. 哪一步最想跳過。
3. 回饋有沒有「真人會這樣講」的感覺，還是變成修句套路。
