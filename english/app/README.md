# English Coach（選單列小工具）

快捷鍵 **⌃⌥E**（Control + Option + E）叫出小視窗，輸入今天聽／讀了什麼，一次一題，打 2～3 句就好。

- 全程安靜，不用開口。
- 沒有連續天數、沒有進度條。
- 卡住時點題目下面的開頭句，會自動填進輸入框。
- **存起來**：存進 App 的「紀錄」分頁，隨時可以點開回頭看。同一筆可以一天內多次「複製並開 Claude」，也可以把 Claude 的回饋貼回來留存（可分次補充）。
- **每日提醒**：預設週一到週五 12:15 跳系統通知，點通知會打開視窗。時間、週末要不要提醒，都在「設定」分頁改。第一次啟動時 macOS 會問要不要允許通知，要按允許。
- **最新一集**：「練習」頁會顯示 BBC 6 Minute English 最新一集（讀公開的 podcast 訂閱源），可以直接打開影片／逐字稿；聽完按「用這集當主題」，或自己寫別的。App 會自動抓這集的逐字稿（BBC 的格式），存進紀錄；「複製並開 Claude」時，**教練規則（精簡版）、逐字稿、你的回答會一起複製**，所以不需要 Project，在任何 Claude 對話都能貼。其他來源（TED、NPR…）沒有自動抓取，可以把逐字稿或記得的重點貼在「選填」欄位，一樣會附上；都沒有的話，Claude 會請你貼重點。讀不到時（沒網路）這張卡片不顯示，其他功能照常。
- 資料在 `~/EnglishCoach/entries.json`（主要資料，請勿手動改），同時輸出 `~/EnglishCoach/export/yyyy-MM.md` 方便閱讀與做週回顧。
- 貼給 Claude 的內容已含教練規則（精簡版，在 `Content.swift` 的 `coachRules`）；改 `../daily-prompt.md` 的回饋規則時，要一起改那裡。

## 編譯

不需要 Xcode，只需要命令列工具：

    xcode-select --install     # 已經有的話會告訴你
    ./english/app/build.sh
    open english/app/build/EnglishCoach.app

「設定」分頁有「登入 Mac 時自動啟動」，讓 ⌃⌥E 隨時能用；如果註冊失敗，把 App 放進「應用程式」資料夾再試。提醒本身不需要 App 開著。

重新編譯前，先從選單列圖示選「結束」。

macOS 升級後如果 `swift build` 抱怨 SDK 版本，到「系統設定 → 一般 → 軟體更新」更新命令列工具。
