🧪 手勢 POC（純瀏覽器端）
這頁在測一件事：手勢辨識能不能完全在手機/筆電瀏覽器裡跑，不需要另外開一台筆電伺服器。 跟現有的夜市／機器人遊戲用的是同一套判定邏輯（往前揮、上下左右揮），差別是這裡改用瀏覽器內建的 MediaPipe（WASM）直接處理鏡頭畫面，不透過 WebSocket。

已知限制：iPhone 上的 Safari 沒有語音辨識 API、也沒有 Web Bluetooth， 跟讀小鸚鵡和 SwitchBot 這兩個功能沒辦法用這個方法搬過來，還是要靠有伺服器的筆電。

需要允許鏡頭權限，而且網址必須是 https 或 localhost（手機瀏覽器的規定）， 用 http://筆電IP:8000 這種區網網址是打不開鏡頭的。
