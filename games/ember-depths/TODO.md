# 餘燼地城：路線圖

每一階段做完都要能玩、能直接部署；不留「改到一半」的版本。
完成的項目打勾，順序可以依試玩感受調整。

## 已定案的方向

- 類型：ARPG（斜角 3D、即時戰鬥），不改成倖存者類或放置類。
- 死亡：輕鬆耐玩。倒下只扣金幣，等級、裝備、選過的卡都保留；不做「每局從頭來」。
- 結構：從「一路往下的 20 層」改成「營地＋遠征」。
- 回訪動力靠營地成長、角色收集、每日懸賞、每週挑戰；不做長時間的計時建造。
- 保留：戰鬥核心、武器決定普攻、餘燼、流派與升級卡、敵人與房間生成、3D 畫面。

## 第 1 階段：營地與遠征（結構重做）✅

- [x] 營地場景：篝火、告示板、商人；倒下或完成遠征都回到營地
- [x] 遠征：從告示板選，第 1 區 2 層、之後 3 層，最後一層是目標（機器人約 3 分鐘一趟，真人預估 5～8 分鐘）
- [x] 遠征目標：獵首領、救人（救回的人住進營地、會說話）
- [x] 結算畫面：用時、擊殺、撿到幾件、賺多少，獎勵箱一件一件翻開
- [x] 區域等級取代樓層數：打倒該區首領才解鎖下一區；第 7 區首領＝通關
- [x] 遠征修飾詞：菁英大軍、狂奔、長夜（風險換獎勵）
- [x] 商人移進營地；每層起點的商人拿掉
- [x] 背包裡可以「放棄遠征」回營地（沒有獎勵箱）
- [x] 舊存檔轉換：樓層換算成區域等級，其餘都保留
- [ ] 第三種目標「收集餘燼」：限時內收集場上散落的餘燼（延後，先看前兩種好不好玩）

## 第 2 階段：營地建築與逐步解鎖 ✅

- [x] 材料：🦴 骨片（擊殺、寶箱）、💎 餘燼結晶（菁英、鑰匙守衛、首領、寶庫）；結算另給一份
- [x] 建築造價＝骨片＋結晶＋金幣，Lv 3 封頂；金幣終於有大去處
- [x] 訓練場：永久訓練搬過來，等級決定訓練上限（5／10／20）
- [x] 倉庫：背包 24 → 30 → 36 → 42 格
- [x] 鐵匠鋪（要先救回鐵匠）：強化搬過來，等級決定強化上限（+3／+6／+8），Lv 3 費用 -20%
- [x] 餘燼祭壇（要先救回祭司）：重選升級卡搬過來；Lv 2、3 出發時自帶餘燼，Lv 3 重選半價
- [x] 獵人公會（要先救回獵人）：告示板可重抽；Lv 2 完成獎勵金幣 +25%；Lv 3 獎勵箱多一件
- [x] 營地外觀：沒蓋是瓦礫，蓋了有擺設，等級越高越多；鐵匠爐火、祭壇光球
- [x] 救回來的人在自己的建築還沒蓋時會提醒你，蓋好後換台詞
- [x] 營地變大；手機直式的資訊列會換行，不再被小地圖蓋住
- [ ] 獵人公會的懸賞（留到第 4 階段的每日懸賞）

## 第 3 階段：角色

- [ ] 「救人」遠征救回的人成為可玩角色（素材包有遊俠、法師、野蠻人）
- [ ] 每個角色有自己的技能池與起始武器，等級與卡片分開養
- [ ] 營地切換角色；材料、建築、倉庫共用
- [ ] NPC 有簡短台詞與個性

## 第 4 階段：回訪內容

- [ ] 每日懸賞：每天三個不同條件的目標，給稀有材料
- [ ] 每週挑戰地城：特殊規則＋獨立的最深紀錄
- [ ] 傳說圖鑑：收集所有傳說效果
- [ ] 成就

## 打磨（可以穿插在各階段之間）

- [x] 前一分鐘：新玩家直接進第一趟遠征、起點就有 3 隻弱怪、約 9 秒第一次升級、第一次通關保底一件傳說
- [x] 撿寶儀式感：傳說掉落有畫面停頓、光環、專屬音效與「★ 傳說 ★」字樣；稀有有短音與光環；獎勵箱逐件翻開
- [ ] 撿寶儀式感（續）：撿起傳說時的特寫、背包裡傳說裝備的發光邊框
- [ ] 裝備圖示：每種武器、護甲有自己的圖，不再用 emoji
- [ ] 真實音效：找 CC0 音效包取代合成音
- [ ] 更多敵人種類（需要找其他 CC0 模型）
- [ ] 傷害數字的大小層次、暴擊特寫
- [ ] 手機按鈕重新排版，減少誤觸；提示框不擋畫面
- [ ] 斜角視角下大片純黑的牆頂
- [ ] 存檔匯出／匯入（現在只存在瀏覽器裡，清掉資料就沒了）

## 做第 1 階段時想到的

- [ ] 一趟遠征的敵人太多（機器人一趟殺 100～340 隻）。真人不會清每個房間，但要觀察會不會太長、太累
- [ ] 營地目前只是一個空房間加篝火，要等第 2 階段的建築才會有「家」的感覺
- [ ] 救人目前只有 5 位，救完就沒有救人任務了；第 3 階段要讓他們變成可玩角色，或改成每日任務的來源
- [ ] 告示板的選項太少（每區一個首領、加上最新區的救人）；可以加「每日遠征」：固定修飾詞、額外獎勵
- [ ] 遠征中途存檔再讀檔，會重新生成目前這一層（怪物會復活）；之後可考慮只存「第幾層」不存進度，這是目前的行為，應該可接受
- [ ] 回營地時血量、魔力自動補滿，藥水存量就沒那麼重要；藥水價格可能要重新看
- [ ] 營地裡可以加「練習木樁」，試新武器、新技能用

## 做第 2 階段時想到的

- [ ] 機器人 10 趟：訓練場到頂、其他多在 2 級、第 10 趟通關第 7 區。中後期瓶頸是金幣、結晶反而有剩；結晶可以再多一個用途
- [ ] 機器人會清光每個房間，真人會比較慢拿到材料；之後看實際回饋再調掉率
- [ ] 機器人整趟 0～1 次倒下：訓練與強化疊上去後，後期偏簡單。難度曲線要跟著建築加成重看
- [ ] 建築只是一組擺設，沒有「建造中」的動畫；可以加施工的粒子或工人
- [ ] 學者 米亞、遊俠 芙蕾 救回來後還沒有對應建築（第 3 階段變成可玩角色）
