# 餘燼地城：路線圖

每一階段做完都要能玩、能直接部署；不留「改到一半」的版本。
完成的項目打勾，順序可以依試玩感受調整。

## 已定案的方向

- 類型：ARPG（斜角 3D、即時戰鬥），不改成倖存者類或放置類。
- 死亡：輕鬆耐玩。倒下只扣金幣，等級、裝備、選過的卡都保留；不做「每局從頭來」。
- 結構：從「一路往下的 20 層」改成「營地＋遠征」。
- 回訪動力靠營地成長、角色收集、每日懸賞、每週挑戰；不做長時間的計時建造。
- 保留：戰鬥核心、武器決定普攻、餘燼、流派與升級卡、敵人與房間生成、3D 畫面。

## 第 1 階段：營地與遠征（結構重做）

- [ ] 營地場景：篝火、告示板、出發點；倒下或完成遠征都回到營地
- [ ] 遠征地圖：從告示板選一張，每趟 3～4 層、5～8 分鐘，最後一層是首領或目標
- [ ] 遠征目標類型：獵首領、救人、收集餘燼（先做兩種）
- [ ] 結算畫面：擊殺、拿到的裝備與材料、用時，開獎勵箱
- [ ] 地圖難度分級（取代現在的樓層數），解鎖下一級要先通關上一級
- [ ] 商人移進營地；每層起點的商人拿掉
- [ ] 舊存檔轉換：保留等級、裝備、卡片、金幣

## 第 2 階段：營地建築與逐步解鎖

- [ ] 遠征掉落「材料」，用來蓋與升級建築
- [ ] 鐵匠：強化裝備（取代商店的強化）
- [ ] 祭壇：流派與重選升級卡
- [ ] 獵人公會：懸賞（接第 4 階段）
- [ ] 倉庫：擴充背包
- [ ] 營地外觀會隨建築等級變熱鬧（模型、火光、NPC）
- [ ] 系統用劇情逐步解鎖：救回鐵匠才有強化、救回祭司才有流派

## 第 3 階段：角色

- [ ] 「救人」遠征救回的人成為可玩角色（素材包有遊俠、法師、野蠻人）
- [ ] 每個角色有自己的技能池與起始武器，等級與卡片分開養
- [ ] 營地切換角色；材料、建築、倉庫共用
- [ ] NPC 有簡短台詞與個性

## 第 4 階段：回訪內容

- [ ] 每日懸賞：每天三個不同條件的目標，給稀有材料
- [ ] 每週挑戰地城：特殊規則＋獨立的最深紀錄
- [ ] 傳說圖鑑：收集所有傳說效果
- [ ] 成就

## 打磨（可以穿插在各階段之間）

- [ ] 前一分鐘：開場就有怪、30 秒內第一次升級、保底早期掉一件傳說
- [ ] 撿寶儀式感：依稀有度分級的音效與停頓、傳說掉落演出
- [ ] 裝備圖示：每種武器、護甲有自己的圖，不再用 emoji
- [ ] 真實音效：找 CC0 音效包取代合成音
- [ ] 更多敵人種類（需要找其他 CC0 模型）
- [ ] 傷害數字的大小層次、暴擊特寫
- [ ] 手機按鈕重新排版，減少誤觸；提示框不擋畫面
- [ ] 斜角視角下大片純黑的牆頂
- [ ] 存檔匯出／匯入（現在只存在瀏覽器裡，清掉資料就沒了）
