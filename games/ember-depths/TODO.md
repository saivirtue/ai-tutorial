# 餘燼地城：路線圖

每一階段做完都要能玩、能直接部署；不留「改到一半」的版本。
完成的項目打勾，順序可以依試玩感受調整。

## 已定案的方向

- 類型：ARPG（斜角 3D、即時戰鬥），不改成倖存者類或放置類。
- 死亡：輕鬆耐玩。倒下只扣金幣，等級、裝備、選過的卡都保留；不做「每局從頭來」。
- 結構：從「一路往下的 20 層」改成「營地＋遠征」。
- 回訪動力靠營地成長、角色收集、每日懸賞、每週挑戰；不做長時間的計時建造。
- 保留：戰鬥核心、武器決定普攻、餘燼、流派與升級卡、敵人與房間生成、3D 畫面。

## 第 1 階段：營地與遠征（結構重做）✅

- [x] 營地場景：篝火、告示板、商人；倒下或完成遠征都回到營地
- [x] 遠征：從告示板選，第 1 區 2 層、之後 3 層，最後一層是目標（機器人約 3 分鐘一趟，真人預估 5～8 分鐘）
- [x] 遠征目標：獵首領、救人（救回的人住進營地、會說話）
- [x] 結算畫面：用時、擊殺、撿到幾件、賺多少，獎勵箱一件一件翻開
- [x] 區域等級取代樓層數：打倒該區首領才解鎖下一區；第 7 區首領＝通關
- [x] 遠征修飾詞：菁英大軍、狂奔、長夜（風險換獎勵）
- [x] 商人移進營地；每層起點的商人拿掉
- [x] 背包裡可以「放棄遠征」回營地（沒有獎勵箱）
- [x] 舊存檔轉換：樓層換算成區域等級，其餘都保留
- [ ] 第三種目標「收集餘燼」：限時內收集場上散落的餘燼（延後，先看前兩種好不好玩）

## 第 2 階段：營地建築與逐步解鎖 ✅

- [x] 材料：🦴 骨片（擊殺、寶箱）、💎 餘燼結晶（菁英、鑰匙守衛、首領、寶庫）；結算另給一份
- [x] 建築造價＝骨片＋結晶＋金幣，Lv 3 封頂；金幣終於有大去處
- [x] 訓練場：永久訓練搬過來，等級決定訓練上限（5／10／20）
- [x] 倉庫：背包 24 → 30 → 36 → 42 格
- [x] 鐵匠鋪（要先救回鐵匠）：強化搬過來，等級決定強化上限（+3／+6／+8），Lv 3 費用 -20%
- [x] 餘燼祭壇（要先救回祭司）：重選升級卡搬過來；Lv 2、3 出發時自帶餘燼，Lv 3 重選半價
- [x] 獵人公會（要先救回獵人）：告示板可重抽；Lv 2 完成獎勵金幣 +25%；Lv 3 獎勵箱多一件
- [x] 營地外觀：沒蓋是瓦礫，蓋了有擺設，等級越高越多；鐵匠爐火、祭壇光球
- [x] 救回來的人在自己的建築還沒蓋時會提醒你，蓋好後換台詞
- [x] 營地變大；手機直式的資訊列會換行，不再被小地圖蓋住
- [ ] 獵人公會的懸賞（留到第 4 階段的每日懸賞）

## 第 3 階段：角色 ✅

- [x] 救回的人裡有三位是可玩角色：遊俠 芙蕾（手弩）、學者 米亞（法杖）、蠻族 布魯（巨劍，新增的救援對象）
- [x] 救援順序調整成第二個就是遊俠，讓第二種玩法早點出現
- [x] 每個角色有自己的模型、起始武器、起始技能、角色特性，選卡時偏向擅長的系別
- [x] 等級、升級卡、身上裝備各自一份；金幣、材料、背包、建築、訓練全隊共用
- [x] 營地走到角色旁邊就能換人出征；沒上場的角色（包括騎士）站在篝火旁，標著等級
- [x] 新角色第一次上場會追上主力八成的等級，多出來的等級變成升級卡
- [x] NPC 有簡短台詞，可玩角色的台詞會邀你換他上場
- [ ] 每個角色專屬的技能（目前只是技能池偏重不同系別）
- [ ] 換角色時的介紹畫面（現在只有橫幅一行字）

## 第 4 階段：回訪內容 ✅

- [x] 每日懸賞：告示板上每天換一批（同一天固定），3 個、蓋了獵人公會變 4 個；完成後回告示板領 💎🦴💰
- [x] 懸賞種類：擊殺、菁英、寶箱、引爆餘燼、首領、指定武器通關、不喝藥通關、帶修飾詞通關
- [x] 每週挑戰：無盡往下，每週換規則（玻璃大砲／長夜／菁英大軍／狂奔），倒下不扣金幣，每 3 層 💎 +2，記錄本週最佳
- [x] 傳說圖鑑：撿到或開箱開到新的傳說效果就登錄，每種 💎 +1
- [x] 成就 17 個（遠征、擊殺、區域、救人、角色、建築、圖鑑、餘燼、懸賞、每週挑戰），達成自動發獎
- [x] 背包裡的「📖 紀錄」：成就、圖鑑、統計
- [ ] 每週挑戰的排行（目前只有自己的紀錄；要和別人比得有伺服器）

## 第 5 階段：餘燼裝備（讓屬性看得見）

已定案：熱度取代鐵匠鋪的 +1～+8 強化；非戰鬥詞綴每件最多一條；熱度的光跟著裝備走，火光顏色與腳印做成可自由搭配的收藏。

**5-1 屬性視覺化** ✅
- [x] 攻擊：命中火花的數量、大小、飛散距離跟著「這一下打掉多少血」走
- [x] 暴擊：專屬音效（高音金屬聲加低音）與鏡頭瞬間拉近
- [x] 移速：移動時腳下揚起塵土，移速超過 20% 變成橙色餘燼
- [x] 護甲：擋下的比例越高，「鏗」的金屬聲與白色火花越多
- [x] 吸血：紅色光點從敵人飛回主角
- [x] 回魔：每秒回魔高於 3.5 時，身邊繞著藍色光點
- [x] 換裝比較：「骷髏兵：3 下 → 2 下」「清怪速度快 39%」

**5-2 熱度** ✅
- [x] 每件裝備有熱度 0～5：冷鐵、暗紅、赤紅、橙熱、金焰、白熾；每級所有數值 +12%
- [x] 穿著戰鬥就會升溫（一般擊殺 1、菁英 3、首領 15），升溫時有提示與特效
- [x] 鐵匠鋪改成「熔鑄」：花金幣直接升一級熱度，上限依鐵匠鋪等級（赤紅／金焰／白熾）
- [x] 舊存檔的 +N 強化自動換算成熱度
- [x] 外觀：身上的武器與盾牌依熱度發光變色；橙熱以上的武器拖火尾，越熱越多
- [x] 白熾：多一條 1.5 倍的「🔥 餘燼詞綴」，沒有非戰鬥詞綴的話也送一條

**5-3 非戰鬥詞綴** ✅（精良以上 22% 機率、傳說 50%，每件最多一條）
- [x] 火光（火把範圍）、尋寶（小地圖顯示寶箱）、警覺（陷阱發紅光、傷害減半）
- [x] 磁吸（撿拾範圍，藥水和裝備也會飛過來）、殺價（商店打折）、幸運（獎勵箱多一件）
- [x] 火痕（火焰腳印）、殘影（閃避殘影）

**5-4 外觀收藏** ✅
- [x] 火光顏色：橙火（預設）、藍火、翠火、紫火、白焰；腳印：餘燼、霜火
- [x] 由成就解鎖（紀錄面板裡的成就會標出解鎖哪個外觀）
- [x] 營地篝火旁可以自由切換，不影響數值

**做第 5 階段時想到的**
- [ ] 熱度只在畫面上看得到武器和盾牌；護甲、飾品沒有外觀，可以讓主角身上發出對應顏色的微光
- [ ] 非戰鬥詞綴目前只有 8 種，玩一陣子會重複；可以加「營地相關」的（例如讓某個 NPC 送你東西）
- [ ] 白熾的武器在手機上粒子很多，要觀察會不會掉幀
- [ ] 背包格子沒有顯示熱度，要點開才看得到；可以在格子角落加小火焰

## 試玩回饋（第 3 次）：先記錄，慢慢做

玩家總評：「真的是爽感遊戲，大概到換了遊俠之後的體驗」→ 前段的爽感成立，中後段開始空掉。下面依「影響中後段動力」的程度排序。

### A. 裝備與掉寶（最核心）
- [x] **橘色（傳說）太容易拿，拿到就不換**（傳說數值範圍、餘燼階已做；套裝還沒做）。原因：傳說只有一種強度，而且 9 種效果很快就湊齊；之後撿到的東西都比不上。
  - 建議：傳說效果做成**有數值範圍**（例如連鎖閃電 2～5 跳），同一個效果也有好壞之分，會想刷更好的那一件
  - 建議：在傳說之上加一階「**餘燼（紅）**」，只在危險度 5 以上、首領或每週挑戰掉落；外觀直接自帶火焰
  - 建議：**套裝**（2 件、3 件觸發效果），讓「撿到一件差一點的，但能湊成套」也有意義
- [ ] **裝備種類太少**：武器 7 種、護甲 4 種、飾品 3 種，沒有頭盔、手套、鞋子
  - 建議：先加「頭盔」「鞋子」兩個欄位（素材包裡騎士、遊俠、法師、蠻族各有帽子或頭盔，可以做成可換的外觀）；詞綴池擴充到 20 種以上
- [x] **危險度只讓怪變耐打，掉寶沒感覺**（傳說機率隨危險度明顯提高、危險度 5 起掉餘燼裝備，告示板寫出這一級多了什麼）。現在每級只多 1.5% 稀有度，太小
  - 建議：危險度直接寫在掉落規則上，而且要看得見：「危險度 3 起才會掉傳說」「5 起掉餘燼裝備」「每級物品等級 +1」，並在告示板列出這一級多了什麼

### B. 經濟
- [x] **裝備買賣應該回營地**：現在背包裡隨時能賣，倉庫擴充背包就沒有意義。改成只有在營地（商人旁）才能賣；遠征中背包滿了只能丟棄或不撿
- [x] **撿裝備可以選擇跳過品質**（背包的「🧲 自動撿」：全部／精良以上／稀有以上／只撿傳說；沒撿的留在地上、名字變淡，走近按「撿起」）：設定「自動撿取：全部／精良以上／稀有以上／只撿傳說」，沒撿的仍顯示在地上，走近可以手動撿
- [x] **錢累積很快**（見「第一份狀態匯出的分析」；新的金幣去處還沒做）：建築升滿後金幣又沒處花。方向：
  - 賣裝備改成在營地賣、價格調低（與上一條一起）
  - 新的金幣去處：重鑄詞綴（花錢把一條詞綴重骰）、熔鑄到更高熱度、商人的「餘燼」商品
  - 機器人跑出來的金幣收入要重新量

### C. 角色與技能
- [x] **遊俠沒意義**（已做：騎士＝劍、斧；遊俠＝手弩、匕首；學者＝法杖；蠻族＝巨劍、斧；非本職武器傷害 -30%、說明欄會標示；掉落武器約八成是本職武器；每個職業 4 個技能，升級卡只出現自己職業的新技能）：武器能隨便撿，遊俠拿巨劍也一樣；技能也沒有綁角色
  - 建議：**職業綁武器類型**（騎士：劍、斧、盾；遊俠：手弩、匕首；學者：法杖；蠻族：巨劍、斧）。拿非本職武器可以，但會少 30% 傷害、而且不能用職業技能
  - 建議：**每個職業有自己的技能池**（共用一部分），例如遊俠：彈幕、陷阱、翻滾射擊、獵人標記；學者：落雷、冰霜新星、火球、傳送
- [ ] **是否做技能樹（待討論）**：
  - 選項 1：維持升級三選一，但卡池依職業分開（改動小）
  - 選項 2：每個職業一棵小技能樹（3 條分支、每條 5～6 個節點），升級點數自己點（改動大，但有長期目標）
  - 選項 3：兩者混合：升級時選卡，另外每 5 級給一個「天賦點」點在技能樹上
  - 我的傾向：選項 3

### D. 除錯與調整工具
- [x] **匯出遊戲狀態**（已完成：背包裡的「📋 匯出狀態」；另外開始記錄最近 15 趟遠征與總遊玩時間）：背包裡加一顆「📋 匯出狀態」，把等級、裝備、卡片、建築、金幣材料、區域、危險度、各種統計整理成一段文字，複製後貼給 Claude，方便判斷難易度和找問題（這一項最先做，後面每次調整都用得到）

### E. 熱度以外的「餘燼」想法（待討論）
- [ ] **裝備有名字和來歷**：熱度到白熾時可以替它取名，裝備說明會記錄「陪你擊殺了幾隻、打倒過哪些首領」
- [ ] **餘燼刻印**：首領會掉「刻印」，嵌在裝備上改變外觀與一條特效（例如武器揮動留下冰痕），讓同一把劍有不同的樣子
- [ ] **獻祭**：把不要的傳說丟進營地篝火，換成餘燼結晶或讓另一件裝備升溫，讓「換掉的舊裝備」也有去處
