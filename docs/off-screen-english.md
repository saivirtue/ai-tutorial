# 不用螢幕的英文活動（給大人）

小一英文學得好不好，大半不是靠螢幕。遊戲最適合做的是「記住、反覆、有趣」；下面這些是遊戲做不到、或做了不如真的動手的部分。每個都不用準備、五分鐘內，挑一兩個就好，不用全做。

配合學校的單字表（Aa～Mm、數字 1～10、生活對話）。

## 1. 手寫：遊戲最缺的一塊

學校單字表是**四線格**，很可能要寫。遊戲沒做書寫，這一塊要靠紙筆：

- 先用手指在**鹽、麵粉或沙**上描大寫、小寫（描的時候念字母名稱）
- 再用鉛筆在四線格上寫，每次只寫 3～5 個字母，寫完讀一次
- 容易搞混的 **b 和 d**：兩手握拳、大拇指朝上，左手像 **b**、右手像 **d**，兩拳靠在一起就是 **bed**（床）。想不起來就看一下自己的手

## 2. 家裡貼英文標籤

用便利貼寫上**真的看得到的東西**，貼在那個東西上：`hat`、`egg`（冰箱裡的蛋）、`cat`、`dog`、`kite`、`fish`（玩具也行）。

- 每個標籤是小孩自己寫的最好；一個字貼一個禮拜，換新的
- 吃飯、出門時順口問：*Where's the hat?* 他指給你看就好，不用他說

## 3. I spy（路上、等待的時候）

*I spy with my little eye something that starts with… C!*（說字母名稱，不是字的音）

- 一開始只用學過的字母 A～M
- 輪流當出題的人。他出題給你猜，你**故意猜錯**一次——教別人是最有效的學習

## 4. 把生活對話放進每天的三個時刻

這些句子的重點是「真的在用」，每天固定三個時刻，換成英文說，三十秒就好：

| 時刻 | 說什麼 |
|---|---|
| 早上見面 | *Good morning.* / *Hi!* / *Hello!* |
| 要出門、要開始做什麼之前 | *Are you ready?* → *Yes.* |
| 排隊、等電梯 | *Line up, please.* |
| 有東西飛來、快撞到 | *Watch out!*（玩傳球時超好用） |
| 分開的時候 | *Goodbye.* / *Bye.* / *See you.* |

## 5. 數字 one～ten

- 爬樓梯、數玩具、數積木時用英文數
- 捉迷藏數到十：*one, two, three…*
- 倒數：*ten, nine, eight…*（發射火箭、出門倒數）

## 6. 兒歌與影片

- 字母歌（ABC song）：邊唱邊指著字母，字母的順序用唱的最快記住
- 學校推薦的 **Starfall**（A～Z 字母動畫）：配合單字表一個字母一個字母看，一次一個就好
- 英文兒歌（數字歌、動物歌）：唱到哪個詞就指給他看

## 7. 一起錄發音，給遊戲用

遊戲裡的英文預設是機器語音，有時唸得怪。**家人自己錄**最好：

- 大約 40 個（字母名稱、13 個單字、10 個數字、11 句對話），清單在 [`audio/README.md`](../audio/README.md)
- 讓小孩當「錄音師」，你唸、他按錄音，也能挑「爸爸版」還是「媽媽版」比較好聽
- 錄好放進 `audio/en/`，遊戲自動優先用你們的聲音
- **大人不用唸得完美**。小孩聽得出你在享受，比聽到完美發音更重要

## 觀察小孩，比任何設計都準

玩的時候不要指導，只看：

- 哪一題他開始**亂按**？那就是他還沒會的
- 哪個遊戲他**最快膩**？先少玩
- 他有沒有**主動問**「這個是什麼意思」？有就是好現象
- 哪個字母或單字**一直錯**？把它單獨拿出來用紙筆練

遊戲裡有個小設計可以參考：選單上每種練習下面的小進度條，是「熟了幾成」。
