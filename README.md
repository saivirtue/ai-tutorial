# 🎪 小小遊戲樂園

和 7 歲小孩一起「做中學」的互動學習遊戲。純 HTML/CSS/JavaScript，零建置工具——改完程式碼、重新整理瀏覽器就能看到結果，非常適合親子一起讀 code、改 code。

## 怎麼玩

### 在筆電上（開發與測試）

```bash
python3 -m http.server 8000
```

然後開瀏覽器進入 `http://localhost:8000`。

### 手機投電視（推薦的遊玩方式）

1. 筆電啟動上面的伺服器，查一下筆電的區網 IP（macOS：系統設定 → Wi-Fi → 詳細資訊）。
2. 手機和筆電連同一個 Wi-Fi，手機瀏覽器開 `http://<筆電IP>:8000`。
3. 手機畫面鏡像投影到電視，小孩拿手機點、全家看電視。

（之後部署到 GitHub Pages 後，手機直接開網址就行，不需要筆電。）

## 遊戲介紹

| 遊戲 | 學什麼 | 玩法 |
|------|--------|------|
| 🎈 數學氣球 | 數量、加減法、反應力 | 螢幕出題，點破正確答案的氣球，集滿 10 顆星星獲勝。三種難度：數一數（1～10）、加法（10 以內）、加減（20 以內） |
| 🤖 指令小機器人 | 邏輯與程式思維 | 排「前進／左轉／右轉」指令，按執行讓機器人一步步走到寶物。撞到石頭不會失敗——修改指令再試，就是除錯的概念！ |

### 和小孩一起改 code 的點子

- **數學氣球**：改 `STARS_TO_WIN` 讓遊戲變長變短、在 `ANIMALS` 加新動物。
- **指令小機器人**：在 `LEVELS` 陣列照樣子加一個新關卡，讓小孩自己「設計關卡」。

## 專案結構

```
index.html              # 遊戲選單首頁
shared/
  style.css             # 共用風格（大字體、大按鈕，給電視距離觀看）
  game-utils.js         # 共用工具：音效、星星計分、慶祝動畫
games/
  math-balloons/        # 數學氣球
  robot-commands/       # 指令小機器人
```
