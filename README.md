# 🎪 小小遊戲樂園

和 7 歲小孩一起「做中學」的互動學習遊戲。純 HTML/CSS/JavaScript，零建置工具——改完程式碼、重新整理瀏覽器就能看到結果，非常適合親子一起讀 code、改 code。

## 怎麼玩

### 有鏡頭的完整玩法（推薦）

```bash
./server/start.sh                  # 用 OAK-D（沒插會自動改用筆電內建鏡頭）
./server/start.sh --source webcam  # 直接用筆電內建鏡頭
```

第一次執行會自動建 Python 環境並安裝套件（幾分鐘）。啟動後終端機會印出手機要開的網址和 QR code：

1. 手機和筆電連同一個 Wi-Fi，掃 QR code（或開 `http://<筆電IP>:8000`）。
2. 手機畫面鏡像投影到電視，全家看電視。
3. 數學氣球會出現 📷 徽章——小孩對鏡頭**比手指**回答，完全不用碰螢幕！觸控也同時可用。

### 純觸控（不需要 Python）

```bash
python3 -m http.server 8000
```

開 `http://localhost:8000`（或手機開筆電 IP）即可，遊戲全部照常玩，只是沒有比手指功能。之後部署到 GitHub Pages 後，手機直接開網址就行。

## 遊戲介紹

| 遊戲 | 學什麼 | 玩法 |
|------|--------|------|
| 🎈 數學氣球 | 數量、加減法、反應力 | 螢幕出題，點破正確答案的氣球，集滿 10 顆星星獲勝。三種難度：數一數（1～10）、加法（10 以內）、加減（20 以內）。開著鏡頭伺服器時可以**比手指回答**（比出的數字穩定一秒就算作答，此時答案自動限制在 10 以內） |
| 🤖 指令小機器人 | 邏輯與程式思維 | 排「⬆️⬇️⬅️➡️」指令，按執行讓機器人一步步走到寶物。撞到石頭不會失敗——修改指令再試，就是除錯的概念！ |
| 🚂 注音小火車 | 注音聲符辨識 | 看圖聽語音（「狗！小狗的狗」），從四個注音裡選出開頭的那個。答對動物就上車，滿八節車廂出發！ |
| 🏆 我的貼紙簿 | 收集的樂趣 | 每次破關隨機得到動物貼紙、達成里程碑拿獎盃，通通存在這裡（記在瀏覽器裡） |

### 語音

遊戲會用瀏覽器內建的中文語音唸題目和鼓勵語（「3 加 2 等於幾？」「哇！你好棒！」），不識字也能自己玩。每個遊戲右上角有 🔊/🔇 可以關掉。裝置沒有中文語音時自動靜默，遊戲照常玩。

### 和小孩一起改 code 的點子

- **數學氣球**：改 `STARS_TO_WIN` 讓遊戲變長變短、在 `ANIMALS` 加新動物。
- **指令小機器人**：在 `LEVELS` 陣列照樣子加一個新關卡，讓小孩自己「設計關卡」。

## 專案結構

```
index.html              # 遊戲選單首頁
shared/
  style.css             # 共用風格（大字體、大按鈕，給電視距離觀看）
  game-utils.js         # 共用工具：音效、星星計分、慶祝動畫
  speech.js             # 中文語音：唸題目、鼓勵語、🔊/🔇 切換
  stickers.js           # 貼紙與獎盃的發放和儲存
  vision-client.js      # 連鏡頭伺服器的 WebSocket 客戶端（連不上就靜默改純觸控）
games/
  math-balloons/        # 數學氣球
  robot-commands/       # 指令小機器人
  zhuyin-train/         # 注音小火車
stickers/               # 貼紙簿頁面
server/
  vision_server.py      # 視覺伺服器：服務網頁 + 鏡頭數手指 + WebSocket 推播
  start.sh              # macOS 一鍵啟動腳本
  requirements.txt
```

### 伺服器小知識

- 影像來源三選一：`--source oakd`（預設）、`webcam`、`mock`（不開鏡頭，用 `GET /mock?count=N` 假裝手指數，測試用）。
- 手指計數用 MediaPipe Hands 在筆電 CPU 跑，雙手加總最多 10。
- 同一個數字穩定比一秒才算「回答」，避免舉手指的過程誤觸發。
