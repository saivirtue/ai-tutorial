# 🎪 小小遊戲樂園

和 7 歲小孩一起「做中學」的互動學習遊戲。純 HTML/CSS/JavaScript，零建置工具——改完程式碼、重新整理瀏覽器就能看到結果，非常適合親子一起讀 code、改 code。

## 怎麼玩

### 有鏡頭的完整玩法（推薦）

```bash
./server/start.sh                  # 用 OAK-D（沒插會自動改用筆電內建鏡頭）
./server/start.sh --source webcam  # 直接用筆電內建鏡頭
```

第一次執行會自動建 Python 環境並安裝套件（幾分鐘）。啟動後終端機會印出手機要開的網址和 QR code：

1. 手機和筆電連同一個 Wi-Fi，掃 QR code（或開 `http://<筆電IP>:8000`）。
2. 手機畫面鏡像投影到電視，全家看電視。
3. 數學氣球會出現 📷 徽章——小孩對鏡頭**比手指**回答，完全不用碰螢幕！觸控也同時可用。
4. 小夜市和指令小機器人會出現 🖐️ 提示——可以**站遠一點用手玩**（見下方「用手玩」）。
5. 跟讀小鸚鵡會**慢慢唸兩次然後自動開始聽**，小孩全程不用碰螢幕。

### 純觸控（不需要 Python）

線上版直接開就能玩：**https://saivirtue.github.io/ai-tutorial/**

想在自己電腦上跑：

```bash
python3 -m http.server 8000
```

開 `http://localhost:8000`（或手機開筆電 IP）即可，遊戲全部照常玩，只是沒有鏡頭和麥克風那些功能（比手指、手勢、跟讀）。

## 遊戲介紹

| 遊戲 | 學什麼 | 玩法 |
|------|--------|------|
| 🎈 數學氣球 | 數量、加減法、反應力 | 螢幕出題，點破正確答案的氣球，集滿 10 顆星星獲勝。三種難度：數一數（1～10）、加法（10 以內）、加減（20 以內）。開著鏡頭伺服器時可以**比手指回答**（比出的數字穩定一秒就算作答，此時答案自動限制在 10 以內） |
| 🤖 指令小機器人 | 邏輯與程式思維 | 排「⬆️⬇️⬅️➡️」指令，按執行讓機器人一步步走到寶物。可以**點指令方塊或按「⌫ 退一步」單獨刪掉一個**，不用整串重排。8 個關卡，後面有走廊、十字形、7x7 大迷宮——地圖不一定是方的。開著鏡頭時可以**朝上下左右揮手排指令、手往前揮＝執行** |
| 🚂 注音小火車 | 注音聲符辨識 | 看圖聽語音（「狗！小狗的狗」），從四個注音裡選出開頭的那個。答對動物就上車，滿八節車廂出發！ |
| 🚂 ABC 字母小火車 | 英文字母認讀 | 玩法跟注音小火車一樣，改成看圖聽英文單字（"Cat! C, Cat!"），選出開頭的大寫字母 |
| 🦜 跟讀小鸚鵡 | 注音拼讀、口說 | 跟注音小火車不同——這個是**練習說出來**。三種模式：**單字**顯示完整拼音（如 ㄋㄧˇ）並拆成一個一個符號方便帶著拼；**三拼**專練 ㄒㄧㄤ、ㄍㄨㄤ 這種「聲母＋介音＋韻母」三個符號的字（小一最容易漏掉中間的介音）；**短句**把注音蓋在國字上面（跟課本一樣）。小鸚鵡會**慢慢唸兩次，唸完自動開始聽**——小孩全程不用碰螢幕。錄音**講完自動停**，想一個一個慢慢拼注音、中間停下來想都不會被切掉；判定也刻意放寬，先拼注音再唸出字一樣算對 |
| 🎪 小夜市 | 純娛樂（動機來源） | 花貼紙玩打地鼠、射氣球、撈金魚、套圈圈，贏了拿獎品 🎁。開著鏡頭時**四攤都能站遠一點用手玩** |
| 🏆 我的貼紙簿 | 收集的樂趣 | 手上的貼紙、夜市獎品、獎盃都在這；獎品集滿一整組就能**跟爸媽換 10 元** |

### 🎟️ 貼紙經濟（為什麼小孩會想學）

```
學習遊戲破關  →  賺到貼紙 🦁
      ↓
花 1 張貼紙   →  玩夜市小遊戲 🎪
      ↓
夜市贏了      →  拿到獎品 🎁
      ↓
獎品集滿一組  →  跟爸媽換 10 元 💰
```

- 貼紙**優先發還沒收集過的**，全部 16 種都有了才會開始重複（不會一直抽到同一張、有幾種永遠抽不到）。
- 收集進度**存在筆電伺服器**（`server/sticker-book.json`），換 Wi-Fi、筆電 IP 變了、關掉電視盒瀏覽器都不會不見。沒開伺服器時就只存在瀏覽器裡。

### 🖐️ 用手玩（不用碰螢幕）

**為什麼做這個：** 用點的一定要走到電視或手機前面，小孩會越靠越近，眼睛和姿勢都不好。開著鏡頭伺服器時，小孩可以站遠一點、用整隻手臂玩。

| 動作 | 意思 |
|------|------|
| 手在鏡頭前移動 | 畫面上的 🖐️ 跟著動（左右已鏡射，像照鏡子） |
| 手往前揮（像真的打出去） | 打地鼠／射氣球／丟圈圈；機器人＝執行 |
| 朝上下左右揮手 | 機器人：排一個那個方向的指令 |
| 把手停著不動 | 撈金魚：網子罩住魚 0.7 秒就撈起來 |

原理很單純，**不需要深度鏡頭**：手靠近鏡頭時，手掌在畫面上會變大——短時間內變大超過一定倍數就判定「往前揮」。因為只看「手掌在哪、多大」，不用看清楚每根手指，所以**比「數手指」還能站得更遠**。

想調靈敏度就改 `server/vision_server.py` 最上面那幾個常數：`PUSH_GROWTH`（要變大幾倍才算揮出去，調小＝比較靈敏）、`SWIPE_DISTANCE`（揮多遠才算）、`GESTURE_COOLDOWN`（兩個手勢之間至少隔多久）。

沒開鏡頭伺服器（例如在 GitHub Pages 上）時，這些全部自動關掉，用點的玩法完全不變。

### 語音

遊戲會用瀏覽器內建的語音唸題目和鼓勵語——中文題目用中文語音（「3 加 2 等於幾？」「哇！你好棒！」），ABC 小火車用英文語音唸單字，不識字也能自己玩。每個遊戲右上角有 🔊/🔇 可以關掉。裝置沒有對應語音時自動靜默，遊戲照常玩。

**覺得語音聽起來像機器人？** 兩個辦法：

1. **換成系統內建的「進階／加強」語音**：macOS 系統設定 → 輔助使用 → 語音內容，下載一個「Mei-Jia（進階）」之類的語音，程式會自動優先選用，比預設語音自然很多。
2. **直接用真人錄音**：跟讀小鸚鵡的範例發音支援本機錄音檔——把錄好的 mp3 放進 `audio/` 資料夾、檔名是要唸的字（例如 `你.mp3`），遊戲會自動優先播放，找不到才退回語音合成。詳見 `audio/README.md`；跟小孩一起錄也是個有趣的活動。
3. **串接教育部辭典發音**（暫緩）：查證過[萌典](https://www.moedict.tw/)的 `/uni/字` API，回傳的 JSON 只有 bopomofo／pinyin／字義，**沒有發音欄位**——發音資料應該是掛在教育部《國語辭典簡編本》而非查到的《重編本》，需要換一個還沒找到的 API 路徑；加上萌典是社群非官方服務、沒有可用性保證，優先度目前不如上面兩個方案高。

### 和小孩一起改 code 的點子

- **數學氣球**：改 `STARS_TO_WIN` 讓遊戲變長變短、在 `ANIMALS` 加新動物。
- **指令小機器人**：關卡就是一張用文字畫的地圖（`.` 是路、`#` 是石頭、空白是沒有地板、`S` 起點、`G` 寶物），讓小孩在紙上畫好再打進 `LEVELS`——這是最好玩的部分，地圖不一定要是方的。
- **小夜市**：改 `MOLE_TARGET`／`BALLOON_TARGET`／`FISH_TARGET`／`RING_TARGET` 調難度，改 `COST` 調一場要幾張貼紙。
- **跟讀小鸚鵡**：在 `THREE_WORDS` 加小孩正在學的三拼字，`accepted` 裡放同音字（語音辨識常常聽成同音字，多寫幾個判定會比較準）。
- **貼紙／獎品**：在 `shared/stickers.js` 的 `STICKER_POOL`、`PRIZE_POOL` 加新圖案。

### 伺服器小知識

- 影像來源三選一：`--source oakd`（預設）、`webcam`、`mock`（不開鏡頭，測試用）。
- 手指計數用 MediaPipe Hands 在筆電 CPU 跑，雙手加總最多 10。手的位置和手勢用的是同一份辨識結果，不用另外跑一個模型。
- 同一個數字穩定比一秒才算「回答」，避免舉手指的過程誤觸發。
- `mock` 模式的測試端點：`GET /mock?count=N`（假裝手指數）、`GET /mock_hand?x=&y=`（假裝手的位置，0~1）、`GET /mock_gesture?name=push` 或 `?name=swipe&dir=left`（假裝手勢）、`GET /mock_speech?text=你好`（假裝聽到的話）。
- 語音辨識**不是固定錄幾秒**，是錄到「不講話了」自動停（`QUIET_LEVEL`／`QUIET_TO_STOP`／`LEAD_IN` 可調）——小孩一個一個慢慢拼注音、中間停下來想，都不會被切掉。

### SwitchBot 實體回饋

四個遊戲在各自的**最終大目標**（氣球集滿星星、機器人全破關、注音／ABC 小火車滿載出發）會透過 WebSocket 通知伺服器，讓 SwitchBot 機械手指按一下實體按鈕——次數不多，比較不傷裝置。

```bash
./server/start.sh --switchbot mock                # 先用這個確認流程通了（不需要真裝置）
./server/start.sh --switchbot AA:BB:CC:DD:EE:FF    # 換成真的 SwitchBot
```

**找 MAC 位址：**

```bash
source server/.venv/bin/activate
python3 server/scan_switchbot.py
```

會列出附近的藍牙裝置，SwitchBot 通常名稱含「WoHand」。掃描前記得先關掉手機上的 SwitchBot App（避免搶著連線）。

**如果按不動：** 現在這版走的是「無密碼」指令。如果你在 SwitchBot App 裡替這顆 Bot 設過密碼（開啟了加密），這版會連線失敗或按了沒反應——這種情況要再加密碼握手的支援，先記在下面的 TODO，回報給我就能繼續做。

### 跟讀小鸚鵡（語音辨識）

```bash
./server/start.sh                # 預設就會開麥克風（--mic on）
./server/start.sh --mic off      # 不想用這功能可以關掉
./server/start.sh --mic mock     # 測試模式：GET /mock_speech?text=波 假裝聽到的話
```

**為什麼用筆電的麥克風，不是手機的？** 瀏覽器基於安全考量，只有 HTTPS 或 `localhost` 才准網頁用麥克風；手機是透過 `http://<筆電IP>:8000` 連進來的，不符合這個條件，麥克風權限會直接被擋掉。所以跟讀功能改成跟鏡頭辨識一樣的架構——**由筆電的麥克風錄音**，小孩對著筆電說話即可（跟站在 OAK-D 鏡頭前的原理一樣），手機/電視只負責顯示畫面。

**運作方式：** 語音辨識用 Google 的免費語音辨識服務（`SpeechRecognition` 套件），**需要網路連線**。

- **單字模式**：練的是完整音節（如 ㄋㄧˇ／你），不是單一注音符號的「呼讀」——完整音節才是正常說話的讀音，辨識準確度高很多。辨識完的文字拿去跟詞庫裡的「可接受同音字」比對，聽起來像就算對。
- **短句模式**：練幾個字組成的完整句子（如「你好」「大家好」），注音蓋在國字上面跟課本一樣。完整句子的語音辨識通常又比單字更準；比對用「差幾個字」寬鬆判斷（容許辨識偶爾聽錯一兩個字），不要求整句一字不差。

兩種模式判斷方式都刻意放寬鬆，不要求咬字完全精準——太嚴格反而會讓小孩挫折。

**如果麥克風完全不能用**（沒裝套件、系統沒給權限）：遊戲畫面會出現一個「🙋 麥克風用不了？點這裡直接算過關」的按鈕，讓爸媽用耳朵判斷、手動點過關，遊戲不會被卡住。

## 📈 台股速查（大人用的獨立工具）

跟上面的兒童遊戲**完全無關**，只是共用同一個 repo 和同一套「純靜態、改完重新整理就看到」的做法。入口沒有放進遊戲選單，直接開 `stock/` 才會看到：

**https://saivirtue.github.io/ai-tutorial/stock/**

### 這一頁刻意「不做」什麼

| 不做 | 為什麼 |
|------|--------|
| 盤中即時報價 | 證交所免金鑰的官方資料只有**收盤後的日頻**。要即時就得自己養 proxy 或買付費 API，那是另一個等級的工程與維護成本 |
| 買賣訊號、短期趨勢預測 | 短期預測是這件事裡最難、最多人做輸的部分。如果一個查詢介面就能看出短期趨勢，那個訊號早就被套利掉了 |
| 自動下單 | 要開戶、券商 API、憑證，而且下錯單會真的賠錢。跟「查詢介面」中間隔了一大段，刻意不混在一起 |

### 這一頁做什麼

都是**慢資料**——變化慢、可查證、不會騙你的那種：

- **查詢**：輸入代號或名稱，本地過濾（全市場資料一次抓完，之後搜尋不再打 API）
- **估值**：本益比／殖利率／股價淨值比，並算出**在全市場的百分位**——「殖利率 4%」沒有感覺，「贏過全市場 82% 的股票」才讀得懂
- **月營收**：年增率（YoY）比月增率有意義，因為月增率受淡旺季影響太大
- **三大法人**：當日買賣超，並明講單日資料雜訊很大
- **自選清單**：存在瀏覽器裡
- **定期定額紀錄簿**：手動記下每次扣款的日期／價格／金額，算出**真實的平均成本**與損益

> 為什麼定期定額是「手動記錄」而不是回測？因為證交所的免費資料沒有個股歷史股價，做不了真正的回測。與其用假設報酬率算一個看起來很專業但其實是編出來的數字，不如記錄真實扣款——而且真實的平均成本本來就是定期定額最該盯的數字。

### 資料來源

全部來自[臺灣證券交易所 OpenAPI](https://openapi.twse.com.tw/)，免金鑰、免註冊、免後端：

| 端點 | 內容 |
|------|------|
| `exchangeReport/STOCK_DAY_ALL` | 個股日成交資訊 |
| `exchangeReport/BWIBBU_ALL` | 本益比／殖利率／股價淨值比 |
| `opendata/t187ap05_L` | 每月營業收入 |
| `fund/T86` | 三大法人買賣超 |

四個端點**各自獨立抓、獨立失敗**——其中一個掛掉不會拖垮整頁，那張卡片會顯示「沒資料」，頁面底部的「▸ 資料源狀態」會列出每一個端點的實際結果與錯誤訊息。證交所改路徑或改 CORS 設定時，看那裡就知道要修哪一個。

**萬一被 CORS 擋住**：頁面底部可以填一個 proxy 前綴（例如自架的 Cloudflare Worker），存在瀏覽器裡，不用改程式碼。含 `{url}` 會把網址編碼後代入，不含就直接接在前面。

### ⚠️ 免責

這些資訊僅供參考，**不構成投資建議**。另外一句老實話：定期定額能贏，恰恰是因為它**不需要你判斷短期趨勢**——靠的是拉長時間把波動磨平。放十年大概率比定存好；放一兩年是擲骰子，沒有任何介面能把那個骰子變成必勝。
